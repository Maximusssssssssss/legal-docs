# ДоксМастер - Юридические документы для ИП и самозанятых

## Быстрый старт

### 1. Настройка Supabase

1. Перейдите на [supabase.com](https://supabase.com) и создайте новый проект
2. В Dashboard перейдите в **SQL Editor**
3. Вставьте содержимое `supabase-schema.sql` и выполните
4. В **Settings > API** скопируйте:
   - `Project URL` 
   - `anon public key`

### 2. Настройка YandexCloud (для ИИ)

1. Перейдите на [console.yandex.cloud](https://console.yandex.cloud)
2. Создайте IAM-токен или API-ключ в разделе **API Keys**
3. Создайте Folder или используйте существующий
4. Скопируйте `folder_id` из URL

### 3. Запуск

```bash
# Установка зависимостей
npm install

# Настройка переменных окружения
# Отредактируйте .env.local - вставьте ключи Supabase и YandexCloud

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build
```

### 4. Деплой на Vercel

```bash
# Установите Vercel CLI
npm i -g vercel

# Деплой
vercel

# Следуйте инструкциям
```

Или подключите GitHub-репозиторий через [vercel.com/new](https://vercel.com/new).

## Структура проекта

```
legal-docs/
├── app/                    # Страницы Next.js
│   ├── page.tsx           # Главная
│   ├── upload/            # Загрузка документов
│   ├── create/            # Создание документов
│   ├── templates/         # Каталог шаблонов
│   ├── dashboard/         # Мои документы
│   └── api/               # API routes
├── components/            # React компоненты
├── lib/                   # Утилиты и шаблоны
│   ├── templates/         # 10 шаблонов документов
│   ├── ai.ts              # Интеграция с YandexGPT
│   ├── supabase.ts        # Клиент Supabase
│   └── validators.ts      # Валидация данных
├── types/                 # TypeScript типы
└── supabase-schema.sql    # SQL-схема для БД
```

## Функционал

- **Загрузка** - OCR-распознавание PDF/сканов с извлечением данных
- **Создание** - Чат с ИИ для создания документов по описанию
- **Шаблоны** - 10 готовых шаблонов для ИП и самозанятых
- **Валидация** - Проверка ИНН, телефонов, паспортных данных
- **Экспорт** - Скачивание готовых документов

## Дисклеймер

Сервис предоставляет шаблоны и помогает в оформлении документов. Не является юридической консультацией.
